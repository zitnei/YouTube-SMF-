音楽 → MIDI 変換

MP3・WAV などの音声から MIDIファイル（SMF形式 .mid）を作ります。どんな音源（PSG・FM・波形メモリ・PCM）で鳴っているかの解析もできます。

ブラウザの中だけで処理するので、ファイルはどこにも送信されません。 パート分けや YouTube リンクからの変換は、パソコンで動かす版で使えます。

ここにファイルをドロップ またはクリックして選ぶ（MP3 / WAV / M4A / FLAC / OGG など）
